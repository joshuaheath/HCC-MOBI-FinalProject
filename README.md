## About the Project

Trading card game (TCG) players often struggle to find local shops that stock the products they need, or simply don't know where to look. This project aims to bring card shops and resellers together in one place so anyone can find what they're after.

## Who Is This For?

This project is for anyone with an interest in card games, at any level:

- **Newcomers:** just starting out and looking for a first shop or starter products.
- **Enthusiasts:** knowledgeable players looking for specific cards, bundles, or packs.
- **Veterans:** experienced collectors and competitors who want to discover new shops and resellers.
